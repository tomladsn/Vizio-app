How it works

From plain English
to executed pipeline

No syntax, no flags, no command memorization. Describe what you want — Vizio plans and runs the work.

01
Describe your goal
Type what you need in plain language. Attach files with @ mentions. Vizio reads the project context and incorporates it automatically.
"Compress the interview, add subtitles, mix in the soundtrack at 30%."
02
Agent plans the workflow
The AI generates a structured multi-step JSON workflow — not a one-liner. Each step is individually tracked in the session log and retried automatically on failure.
03
Tools execute each step
ffmpeg, Whisper, yt-dlp, ImageMagick run the real work. Real-time per-step progress, full stdout/stderr logs, and batch processing across multiple files.
04
Self-healing on failure
If a step fails, the AI reads the full error log, diagnoses the cause — wrong flag, bad path, missing codec — and retries with a corrected command. Up to 3 attempts.

Features

Everything in one workspace

AI workflow generation
Describe the goal. The agent plans a structured multi-step workflow with individually trackable steps and full session logging.
Self-healing execution
On failure, the AI reads stderr, identifies the root cause, corrects the command, and retries — up to 3 attempts per step, automatically.
Project management
Work organized into projects with dedicated input, output, and session folders. Every AI decision is saved to the session log.
Media library
Visual file browser with drag-and-drop import. Mention files with @ in chat to give the AI context about what to process.
Before / After preview
See input and output side by side directly in the app — no switching to an external player to check your results.
Multi-provider AI
Groq, Anthropic, OpenAI, Ollama (local), or any OpenAI-compatible endpoint. Switch models from Settings without breaking your workflow.
